# Breast-Cancer-Detection-Model
This repository contains a project focused on breast cancer (BC) detection. Data is derived from the ‘Breast Cancer Wisconsin (Diagnostic) Data Set,’ including various health metrics such as diagnosis, radius, texture, and more. The primary objective is to create a predictive model that accurately determines whether or not individuals are at risk of BC. In creating this machine learning python program, early detection of BC can be facilitated, which can then greatly improve prognosis and survival chances.
